[1:10 to 2:00] The system is written in Python: NumPy for the vector search, matplotlib for the phone drawing and Streamlit for the interface. The language replies behind our results were recorded earlier, from a first version of the page, and the app plays them back. We split the work in two. Claude handles language: it reads the person and explains the result, though in the offline demo that explanation comes from a template. Python handles everything that has to be correct. The need and every candidate phone sit in the same nine-axis vector space. We filter by space, budget and dependencies, rank what’s left, then place the modules using heat, antenna and grip rules. Cosine alone would reward a weak phone with the right shape, so we add attainment, with needs squared so top priorities dominate. We compared three prompts, v1 to v3, each adding more structure, as listed on the slide.
